# StockScan Inventory Dashboard

## Overview
StockScan is a full-featured inventory management web portal that connects to an external NestJS backend at `https://api.stockscan.uk`. The frontend is built with Next.js 14 (App Router) and deployed at `https://login.stockscan.uk`.

## Technical Stack
- **Frontend**: Next.js 14, TypeScript, Tailwind CSS
- **Charts**: recharts (for reports)
- **API Client**: Custom `lib/api-client.ts` with token-based auth proxied through `/api/proxy/[...path]`
- **Auth**: Custom auth context with JWT tokens stored in cookies
- **Backend**: External NestJS API at `https://api.stockscan.uk` (NOT in this project)

## Key Architecture
- Backend returns `token` (not `access_token`) from login
- Job card endpoints use `/job-cards/` prefix (no `/api/` in proxy path)
- Allocations endpoint returns array directly, not wrapped object
- **Delivery system (v1.14.1)**: Unified delivery system handling CUSTOMER deliveries and TRANSFER delivery notes. DeliveryType: CUSTOMER | TRANSFER. FulfillmentMethod: DELIVERY | COLLECTION. Status: PENDING | DELIVERED | COLLECTED | CANCELLED. Signature via `/api/deliveries/:id/signature` (auto-sets status based on fulfillmentMethod). POS uses `createDeliveryFromSale(saleId)`. Stock transfers use `createDeliveryFromTransfer(transferId)`. PDF auto-adapts. Standalone stock transfer detail page removed (redirects to /deliveries). Delivery creation requires `productId: null`, `sku`, `productName` format for Sage imports

## Modules Implemented (v1.7.4)
### Phase 1 - Job Cards Enhancements
- **4-tab layout**: Materials, Labour, Activity, Notes
- **Status workflow**: OPEN → IN_PROGRESS → COMPLETED → CLOSED with dynamic action button
- **Invoice generation**: via `GET /job-cards/:id/invoice`
- **Sage CSV export**: via `GET /job-cards/:id/export-sage`
- **Activity log**: Timeline UI from `GET /job-cards/:id/activity`
- **Notes**: Editable textarea, PUT `/job-cards/:id/notes`

### Phase 2 - Reports Module (`/reports`)
- Sales, Stock, Job Cards, Profit & Loss tabs
- Date range filtering, CSV export
- recharts charts (Line, Bar, Pie)
- P&L tab restricted to OWNER role

### Phase 3 - POS Module (`/pos`)
- New Sale view: product search, cart, payment method selection, checkout
- Sales History view: table with sale details, refund capability
- Receipt generation in popup window
- Payment methods: Cash, Card, Transfer

### Phase 4 - Branding & Feature Flags (`/branding`)
- Company branding: name, logo URL, primary/secondary colors with preview
- Feature flags toggle: all 8 feature modules can be enabled/disabled
- OWNER-only access
